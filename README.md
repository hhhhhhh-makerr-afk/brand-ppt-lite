# 品牌／企业介绍 PPT 排版 · Lite

把品牌资料、公司介绍、服务清单和案例，整理成有逻辑、有依据、有视觉方向的介绍PPT。

这是 `brand-ppt-lite` 独立轻量版，免费分享、源码可见。无需安装作者的其他私有PPT技能。它提供工作流程与排版规则；生图、PPTX导出与渲染由使用环境提供。

**[下载技能安装包](downloads/brand-ppt-lite.zip)** · **[查看技能正文](brand-ppt-lite/SKILL.md)** · **[使用许可](LICENSE.txt)**

## 可以用来做什么

- 品牌介绍、品牌故事与小店介绍。
- 公司介绍、服务商能力展示与工作室介绍。
- 招商合作介绍、团队或个人IP介绍。

侧重品牌与组织介绍；以产品功能、规格和购买决策为主的资料，可查看同系列 [产品介绍 PPT Lite](https://github.com/hhhhhhh-makerr-afk/product-ppt-lite)。

## 制作流程

1. **实际读资料**：核对主体、数字、项目状态和素材权限。
2. **规划整份内容**：输出逐页文案、排版规划、原文覆盖表和待核事项。
3. **建立视觉方向**：根据你的品牌规范和参考图提取色彩、字图关系与页面节奏，不锁死一种风格。
4. **先做代表页**：先验证主视觉和信息较多的页面，再分批制作。
5. **检查与交付**：核对文字、事实与素材；环境支持时继续制作并验证PPTX。

已有真实使命、团队、客户和案例按资料表达；缺少这些材料时，不会为了凑页数而编造。

## 怎么安装

1. 点击上面的安装包链接，在文件页点击下载按钮。
2. 解压，得到 `brand-ppt-lite` 文件夹，内含 `SKILL.md`、`agents`、`references` 和 `assets`。
3. 按所用工具的技能安装说明导入这个文件夹，或放入该工具规定的技能目录。不同工具的安装入口与兼容情况不同。
4. 在支持该调用方式的环境中，输入 `$brand-ppt-lite` 并提供资料。

安装包是技能说明与配套资料，不是独立运行的软件，也不包含生成模型、字体或付费服务。

## 交付边界

- 没有生图工具时，可以完成规划和逐页中文视觉提示词，不能声称已生成页面。
- 图片视觉稿、PDF与对象级可编辑PPTX是不同交付物。整页图片放入PPT，不等于页面对象可编辑。
- AI处理可能改变产品比例与纹样。需要准确呈现实物时优先直接嵌入原图，不将生成场景当作实拍证据。
- 不保证一键完成、产品像素不变、任意工具兼容或商业转化效果。
