# 来源与提取范围

原教程：[《【品牌/企业介绍】适用于品牌企业公司介绍PPT》](https://chenmu-tech.feishu.cn/wiki/UO6XwtxEhidN1YkHUpQcsM5CnOc)。已实际读取规划提示词全部243行、逐页视觉提示词全部103行、第三步生成与修改说明，并查看苹果公司介绍示例缩略页。

本技能为重新编写的可执行规则，不是教程全文、原作者资产或授权背书。无需重新访问教程即可独立执行，不附教程中的图片、客户资料、Logo、字体或外链工具。

| 原教程方法 | 独立版处理 |
|---|---|
| 规划报告→提示词→逐页视觉生成 | 保留阶段与不同交付物边界 |
| Why–How–What、案例证明、信任背书、合作转化 | 保留叙事逻辑，按受众与已有证据选页 |
| 需求清单、叙事策略、逐页标题/正文/作用 | 增加原文覆盖、事实性质、冲突与主体归属 |
| 信息不足可作合理假设 | 只允许明确的设计/受众假设，不补使命事实、客户、资质或业绩 |
| 风格推断并在后续提示词中继承 | 提供单一默认风格，可由品牌规范和参考图覆盖 |
| 主视觉、矩阵、时间线、案例、客户墙等 | 仅在材料与用途支持时采用，不造视觉背书 |
| 使用自己的配图，逐页生成，修改提示词后再生成 | 加入代表页、分批和生成结果复核 |
| 外链图片转PPTX教程 | 不打包外部转换器；只在环境支持时制作并核验可编辑文件 |

原教程中10页与20页框架用于解释拆分方法，不成为缺失证据也必须填满的要求。原作者示例不作为本技能已复现案例；本包的工作室简报为虚构测试资料。
