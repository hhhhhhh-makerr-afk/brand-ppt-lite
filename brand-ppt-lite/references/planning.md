# 品牌叙事与页面合同

## 按受众组织认知

| 用途 | 应回答的决策问题 | 优先证据 |
|---|---|---|
| 品牌认知/品牌故事 | 是谁、为何存在、代表什么、如何兑现 | 已定义主张、真实背景、产品/服务与作品 |
| 公司/服务商介绍 | 服务谁、做什么、如何交付、为何可信 | 业务边界、流程、项目角色、真实案例与成果 |
| 招商/合作介绍 | 合作对象、支持内容、责任边界、怎么对接 | 已确认合作机制，不推算回报或补造合同条件 |
| 团队/个人IP | 本人或团队做过什么、负责什么、怎样合作 | 可核对经历和作品，个人与任职公司成果分开 |

推荐Why–How–What + Proof + Trust + CTA作为可调整骨架：主张/定位 → 需求背景 → 理念 → 业务 → 方法与能力 → 故事/历程 → 案例 → 团队/资源 → 合作。不要硬塞没有材料的章节；品牌介绍不等于替用户做品牌战略决策。

## 页数与任务

短介绍可合并为6页：封面与定位、对象与理念、业务总览、交付能力、案例或真实作品、合作方式。资料不足时可做3–4页；无案例可用有依据的工作方法替代，但不能称“案例证明”。

约10页可拆定位、需求背景、使命、业务、能力、故事、案例、背书、合作等主题；约20页可按业务模块、能力和案例展开。页数不是证据要求的例外，不能为了填满20页造三项业务或三条成果。

## 规划报告必交内容

1. 已读材料及未读原因；需求清单（主题、主体、受众、目的、页数、材料、风格）。
2. 叙事策略：选择此顺序的理由、观众应记住的观点与对应证据。
3. 设计规格：画幅、具体色值、字体层级、主图方式、图形语言与页间节奏。
4. 逐页准确文案和下面的页面合同，不能仅列“品牌实力页”等空目录。
5. 原文覆盖表、冲突/缺项及需要用户确认的主张建议。

## 案例页合同

真实背景/客户（允许披露范围）→ 任务 → 本方承担的角色与行动 → 已提供结果 → 时间与口径。缺少结果数据时写实际交付，不添加增长图；提案或练习稿明确标注，不写成客户已采用。图像服务于案例，而非借名牌Logo制造背书。
