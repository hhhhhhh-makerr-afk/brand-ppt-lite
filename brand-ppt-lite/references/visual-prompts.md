# 品牌视觉与逐页提示词

## 一套默认方向

无品牌规范与参考时，用编辑式品牌手册风：暖白#F5F3EE、墨黑#202020、灰#72726E、单一克制强调色#6B7467；标题48–64px、正文24–28px（1280×720基准），来源限定不小于清晰可读的尺度，最终看实际渲染。中文默认无衬线，品牌需要时可用可用的宋体/衬线标题。

品牌手册、用户指定配色和新参考优先覆盖默认值。先定义色值、字体、网格、照片明暗/裁切、图形线条和页码系统，全稿一致。不要继承其他项目的红色或把器物的新中式风格强加给科技公司。

## 构图随任务变化

| 页面任务 | 视觉表达 | 核验点 |
|---|---|---|
| 封面/定位 | 大幅品牌图、真实人物或作品主图，短主张与留白 | 主体身份、Logo真实性、主张已确认 |
| 理念/背景 | 简洁大字、关键词关系或有依据的情境图 | 观点来源，不造行业数据 |
| 业务/服务 | 服务矩阵、层级或交付对象关系 | 真实业务、边界与关系，不堆装饰卡片 |
| 方法/能力 | 工作流、输入输出、角色分工 | 不把建议流程说成已验证公司制度 |
| 历程/故事 | 日期与事件对应的时间轴或作品序列 | 时间、主体、事件均有证据 |
| 案例 | 大幅作品配任务/行动/结果，按需前后对照 | 前后基准一致，数字与角色不夸大 |
| 团队/背书 | 真实肖像与岗位、资质信息或获授权Logo | 身份、资质时效与客户关系 |
| 合作 | 合作步骤、责任范围和真实联系路径 | 不编联系人、报价、收益与承诺 |

只有真实数字关系才用统计图。品牌故事有情绪，业务和案例可比较、可检索；用主辅图尺度、疏密和构图变化形成节奏，不把全稿排成同一种左右分栏。真实摄影、人物或场景只在有意义且证据许可时加入，不为“高级”强加虚构人物。

## 每页一段独立中文提示词

必须包含：

1. “16:9横屏高清PPT页面”或已定尺寸、该页用途。
2. 选定的风格、具体色值、字体与字级、背景和图形语言。必要规则逐页重复，不只写“同上一页”。
3. 主标题、副标题（按需）、完整正文逐字列出，数字、角色、时间与限定语保留。
4. 真实Logo/人物/产品/案例素材的文件名与角色，保持主体外观比例、颜色、结构；概念素材的可见示意标签。
5. 图片与文字的位置、面积、留白、对齐、阅读顺序和本页可视化。
6. 禁止新增核心判断、品牌卖点、客户、效果数字或资质；不要伪文字、错字和额外Logo。

规划缺项先核对，不在提示词里发明内容。页面内不写“此处放标题/Logo”等占位语，不让制作旁白进入客户阅读正文。已认可方向不重新发散。

## 独立示例（虚构）

16:9横屏高清PPT页面，面向零售品牌项目负责人的工作室介绍。暖白#F5F3EE、墨黑#202020、强调色#6B7467；中文无衬线，标题56px、正文26px，边距64px。标题准确写“让小空间，有清楚的使用秩序”，副标题准确写“溪照空间工作室｜定位文案建议稿”，正文准确写“零售小空间与展陈设计”“概念设计｜深化设计｜现场设计配合”。右侧以基于三项服务的横向流程为主视觉，左侧标题与文字有充足留白；底部准确写“虚构演示”。不画真实门店、客户Logo、团队肖像或奖项，不添加工程施工、造价保证、门店业绩或服务年限。此流程只是服务顺序示意，不作为真实项目交付验证。

## 执行检查

逐页生成并实际查看，先封面与密页，再批量延续。文字错误先修正；精确数字、少见字和表格可改用原生PPT对象。成图中的AI场景不能变成事实照片。工具没有4K或编辑功能时，不声称已经实现。导出PPTX后说明哪些对象能编辑，不把整页图片说成可编辑设计。
